# Excel出力レイアウト設計

## 設計の流れ

**用紙サイズとエントリー数から変換係数を導出する**

### Step 1: mm基準で写真サイズを計算

```
A4: 210mm × 297mm
余白: 上下左右10mm、画像間10mm×2

残り高さ = 297 - 10×2 - 10×2 = 257mm
1枚の写真高さ = 257 ÷ 3枚 = 85.67mm
1枚の写真幅 = 85.67 × 4/3 = 114.2mm (CALS 4:3比)
```

### Step 2: Excel行高さを決定

行高さはptで直接指定可能。
```
写真高さ 85.67mm = 242.9pt (1mm = 2.835pt)
10行で分割 → 1行 = 24pt
```

### Step 3: 列幅の変換係数を実測で求める

**Excel列幅は独自単位のため、実測が必須**

1. 行高さ24pt × 10行 = 240pt（写真高さ）
2. 4:3比で幅 = 320pt
3. Excelで320pt相当の列幅を実測 → **52.75単位**
4. 変換係数 = 320pt ÷ 52.75 ≈ 6.07pt/単位

### Step 4: 情報欄幅の計算

```
A4利用可能幅 = 210 - 10×2 = 190mm
写真幅 = 114.2mm
情報欄幅 = 190 - 114.2 = 75.8mm

Excel単位 = 75.8mm × 2.835pt/mm ÷ 6.07pt/単位 ≈ 35.4
→ 実測で36に調整（ラベル10 + 値26）
```

### Step 5: スケール調整

全体を1.1倍にする場合:
- 行高さ: 24 × 1.1 = 26.4 → 26pt（floor）
- 列幅: 実測で56.1に調整（アスペクト比維持）

## 変換係数まとめ

| 変換 | 係数 | 備考 |
|------|------|------|
| mm → pt | 2.835 | 正確 |
| pt → Excel列幅 | ÷6.07 | 実測値、誤差あり |
| Excel行高さ | pt直接 | 正確 |
